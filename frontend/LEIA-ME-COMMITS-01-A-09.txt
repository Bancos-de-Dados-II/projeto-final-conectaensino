COMO APLICAR

1. Faça um backup ou commit do frontend atual.
2. Extraia TODO o conteúdo deste ZIP dentro da pasta frontend.
3. Permita substituir os arquivos existentes.
4. Não extraia dentro de frontend/src.
5. Na pasta frontend, execute:

npm install
npm install axios react-router-dom lucide-react leaflet react-leaflet chart.js react-chartjs-2 xlsx jspdf jspdf-autotable
npm install -D @types/leaflet
npm run dev

ARQUIVO .ENV DO FRONTEND

Crie/ajuste frontend/.env:

VITE_API_URL=http://localhost:3000/api
VITE_CHAT_WS_URL=ws://localhost:3000/ws/chat
VITE_MAINTENANCE_MODE=false

IMPORTANTE

O backend precisa estar executando e o .env do backend deve possuir as
variáveis exigidas pelo projeto, inclusive SUPABASE_URL e SUPABASE_KEY.

O mapa básico do OpenStreetMap pode aparecer sem registros, mas os marcadores
de alunos/monitores dependem dos endpoints do backend e de coordenadas válidas.
